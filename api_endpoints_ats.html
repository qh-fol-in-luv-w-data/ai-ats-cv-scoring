AI ATS API Endpoints

Danh sách các câu lệnh cURL cho toàn bộ 6 endpoints của dự án 2as-ats theo đúng format chuẩn. Bấm nút Copy để sao chép nhanh.

1. ai_ats.api.generate_candidate_report (POST)

Đánh giá toàn diện hồ sơ ứng viên bằng AI từ các nguồn (CV, Bài Test AI, Test 5G, Phỏng vấn) và lưu báo cáo.

curl -X POST "https://devapp.ctpai.vn/api/method/ai_ats.api.generate_candidate_report" \
  --header "Authorization: token 539cc7c60b48834:451f510c38b665d" \
  --form 'cv_file=@/path/to/cv.pdf' \
  --form 'jd_text="Yêu cầu vị trí Senior Fullstack..."' \
  --form 'ai_test_url="http://10.6.10.12:8069/survey/print/c5094f3b-..."' \
  --form 'g5_test_url="http://10.6.10.12:8069/survey/print/df4405cb-..."' \
  --form 'eq_test_url="https://jobtest.vn/kq-bai-test-abc"' \
  --form 'survey_url="http://10.6.10.12:8069/survey/result/819/..."' \
  --form 'api_use_cache="1"'

2. ai_ats.api.generate_candidate_only_report (POST)

Đánh giá toàn diện hồ sơ (tương tự endpoint số 1, dành cho case riêng biệt).

curl -X POST "https://devapp.ctpai.vn/api/method/ai_ats.api.generate_candidate_only_report" \

  --form 'g5_test_url="http://10.6.10.12:8069/survey/print/df4405cb-..."' \

  --form 'survey_url="http://10.6.10.12:8069/survey/result/819/..."' \
  --form 'api_use_cache="1"'

3. ai_ats.api.score_tests (POST)

Chấm điểm bài test, trả ra bảng chi tiết (AI Test / SWAT / 5G) để Review (Không lưu Database).

curl -X POST "https://devapp.ctpai.vn/api/method/ai_ats.api.score_tests" \
  --header "Authorization: token 539cc7c60b48834:451f510c38b665d" \
  --form 'cv_file=@/path/to/cv.pdf' \
  --form 'jd_text="Yêu cầu vị trí Senior Fullstack..."' \
  --form 'ai_test_url="http://10.6.10.12:8069/survey/print/c5094f3b-..."' \
  --form 'g5_test_url="http://10.6.10.12:8069/survey/print/df4405cb-..."' \
  --form 'eq_test_url="https://jobtest.vn/kq-bai-test-abc"' \
  --form 'survey_url="http://10.6.10.12:8069/survey/result/819/..."' \
  --form 'api_use_cache="0"'

4. ai_ats.api.score_single (POST)

Chấm riêng biệt 1 bài test cụ thể. Tham số type phải là "ai" hoặc "5g".

curl -X POST "https://devapp.ctpai.vn/api/method/ai_ats.api.score_single" \
  --header "Authorization: token 539cc7c60b48834:451f510c38b665d" \
  --form 'url="http://10.6.10.12:8069/survey/print/c5094f3b-..."' \
  --form 'type=ai' \
  --form 'api_use_cache="1"'

5. ai_ats.job_matcher.match_candidate_jobs (POST)

Phân tích CV và chấm điểm độ phù hợp của ứng viên với một danh sách các công việc.

curl -X POST "https://devapp.ctpai.vn/api/method/ai_ats.job_matcher.match_candidate_jobs" \
  --header "Authorization: token 539cc7c60b48834:451f510c38b665d" \
  --form 'cv_file=@/path/to/cv.pdf' \
  --form 'jobs_json="[{\"id\": 1, \"title\": \"AI Engineer\", \"jd_text\": \"Yêu cầu Python...\"}]"'

6. ai_ats.api.get_context (GET)

Entry point cho Frontend khởi tạo Session & CSRF Token. 

curl -X GET "https://devapp.ctpai.vn/api/method/ai_ats.api.get_context" \
  --header "Authorization: token 539cc7c60b48834:451f510c38b665d"
